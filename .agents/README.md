# Agent configuration ownership

The eight project roles are registered in .codex/config.toml and defined under
.codex/agents. AGENTS.md defines their orchestration and authorization boundaries.

.agents/skills/graphify is the generic Agent Skills installation generated by
mise run install-graphify. .codex/skills/graphify is the Codex-specific variant.
Do not manually fork these generated skill files. Upgrade the pinned Graphify
version and rerun installation when an upstream update is intentional.

The canonical graph is graphify-out/graph.json in this repository, generated by
mise run graphify-update and ignored by Git. MCP configuration points to the
same file. Skill installation/configuration does not prove a host loaded it.
