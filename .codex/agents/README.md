# Codex 角色設定

每個 TOML 檔案定義一個角色的名稱、用途與工作指引。由上層的[角色註冊設定](../config.toml)查找角色對應的設定檔。角色選擇與交接方式見[開發流程](../../docs/development/workflow.md)。

共用操作維護於[開發角色共同工作指引](../../docs/development/tooling/agents/README.md#開發角色共同工作指引)。TOML 的 `developer_instructions` 要求角色先讀該節，並保留角色專屬職責、權限界線與交付要求。

修改角色前閱讀[本層工作指引](AGENTS.md)。Codex Cloud 初始化與 MCP 設定見[專案設定說明](../README.md)。

[Explorer](explorer.toml) 查證已發布的 GitHub 來源；[Documentation](documentation.toml) 維護明確授權的 Wiki 頁面。
