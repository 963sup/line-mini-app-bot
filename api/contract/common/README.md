# api/contract/common 目錄導覽

## 用途與範圍

保存各領域 API 共用的 HTTP 傳輸契約。

## 架構與責任邊界

維護共用的 HTTP 傳輸定義，例如認證與錯誤回應。領域操作與業務型別由各能力維護。
