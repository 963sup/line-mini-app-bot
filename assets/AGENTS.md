# Asset module rules

This file adds asset-specific rules to the [repository rules](../AGENTS.md). Directory navigation belongs in the [root README](../README.md#%E5%B0%88%E6%A1%88%E7%B5%90%E6%A7%8B).

- **Source integrity.** Asset names, dimensions, formats and click regions MUST remain aligned with their consumers. Packaged copies MUST NOT become independent sources.
- **Build compatibility.** Contributors MUST verify that changed assets are included in generated menus and container build contexts.
- **Publication safety.** Editing local assets does not authorize publishing LINE menus. Authorized publication MUST preserve a recoverable prior version.
