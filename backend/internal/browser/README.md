# backend/internal/browser 目錄導覽

## 用途與範圍

提供瀏覽器頁面路由與靜態檔案服務，負責將頁面請求交給對應資源。

## 架構與責任邊界

依目錄用途提供後端入口或共用能力；服務接線由 server 負責，資源授權與使用案例歸各業務領域。
