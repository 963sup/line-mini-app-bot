# Attendance valueobject

沒有識別的業務值與驗證。

## 實作與規則

[區間](interval.go) 與 [定位](position.go) 以值傳遞，驗證方法不修改接收者；[補正鍵](correction_key.go) 與 [請假鍵](leave_key.go) 驗證重送識別格式。為保留既有證據與序列化格式，區間仍可表示未結束或不合法時段，由計算回報異常。呼叫端不得原地修改共享切片中的值；需要調整時複製後替換。
