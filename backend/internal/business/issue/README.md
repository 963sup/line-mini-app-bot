# 空間問題

## 用途與範圍

管理 Repository 中的問題事項及其狀態，維護問題專屬的操作與授權規則。

## 架構與責任邊界

此目錄維護本領域或子能力的行為。HTTP、LINE 與 Firestore 依需要提供適配，授權和狀態規則歸資源所屬領域。

## 閱讀與修改入口

先查閱[issue.go](issue.go)、[本目錄工作指引](AGENTS.md)。
