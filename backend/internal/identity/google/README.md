# backend/internal/identity/google 目錄導覽

## 用途與範圍

驗證 Google 身分憑證，供後端確認呼叫端身分。

## 架構與責任邊界

依目錄用途提供後端入口或共用能力；服務接線由 bootstrap 負責，資源授權與使用案例歸各業務領域。
