# backend/internal/navigation/lineui 目錄導覽

## 用途與範圍

建立 LINE 導覽選單的訊息內容與按鈕，供導覽流程共用。

## 架構與責任邊界

依目錄用途提供後端入口或共用能力；服務接線由 bootstrap 負責，資源授權與使用案例歸各業務領域。
