# backend/internal/persistence 目錄導覽

## 目錄用途

集中資料存取的共用工具，包含 Firestore 鍵值與游標處理，以及 gRPC 錯誤對應。

## 閱讀入口

從 [firestorekey](firestorekey)、[grpcstatus](grpcstatus) 開始閱讀。修改前請參考[本目錄工作指引](AGENTS.md)。
