# 實作契約與待決策清單

> 狀態：技術基線已定義；業務功能仍待選定。不得把 proposed／blocked 項目當成已核准產品規格。

## 第一個可實作切片

平台驗證切片（技術基線）：接收 user/group Webhook、驗簽、持久接收、去重與 source 分流，提供 health/readiness。
本切片不執行任意 Postback、不授予群組管理權、不自動 Push；未知事件安全記錄中繼資料並忽略。
完成條件：測試空事件、多事件、重送、錯誤簽章、保存失敗、未知來源、standby 不發送、缺少 actor。
這個切片能先開始，不等於完整業務產品。

## 功能契約範本

每個使用案例在 docs/features/ 下建立具名頁面，確定需求才新增。
必填：目標／非目標、actor、觸發來源、輸入欄位與限制、信任邊界、授權、前置條件、狀態轉移、交易讀寫、外部副作用、冪等鍵、錯誤碼、成功／失敗範例、測試命令、驗收、待決策。
每個函數列出所屬檔案、signature、參數可信度、回傳與錯誤、取消與期限，不只列函數名稱。
