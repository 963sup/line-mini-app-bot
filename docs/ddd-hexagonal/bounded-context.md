# 限界上下文（Bounded Context）

界定一套模型、語言與規則在哪裡有效。

出勤中的 Session 是一次班次；身分驗證中的 Session 是登入工作階段。兩者生命週期、擁有者及結束條件不同，跨邊界時應交換必要事實。Subdomain 劃分業務問題空間，Bounded Context 劃分模型與解決方案空間。兩者不是同義詞，也不必一對一。

上下文邊界界定模型的適用範圍；[Aggregate](aggregate.md) 界定規則的一致性範圍。一個上下文可有多個 Aggregate，資料夾或部署單位也不能單獨證明上下文邊界。

**設計產出**　標明模型擁有者、可執行的決策、跨界契約，以及必須一起成立的規則。
