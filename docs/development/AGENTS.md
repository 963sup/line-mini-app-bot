## 維護與驗證

先讀 [本目錄索引](README.md) 與 [文件總索引](../README.md)。新增或搬移文件同步更新兩層索引及相關模組連結，保留跨模組規格的單一來源。
純文件修改驗證本機路徑、標題錨點及 `git diff --check`；設定變更另依父層規定檢查。不把未執行的應用測試或外部驗收宣稱為通過。
