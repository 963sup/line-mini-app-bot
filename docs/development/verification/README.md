# Development acceptance

Select checks by actual changes, run applicable commands after integration and determine deliverable scope from environment evidence.

1. Combine applicable rows from the [acceptance matrix](../tooling/testing/commands.md#變更驗收矩陣).
2. Record commands, results and unverified environments using [evidence/limitations](evidence.md).
3. For continued work, check [evidence reuse conditions](../workflow/handoff.md#minimal-handoff-and-evidence-reuse).

[36 項標準化驗收紀錄](standardization.md) records the current local/emulator scope, evidence milestones and outstanding environment acceptance.

[全庫標準化盤點與批次整改清單](standardization-backlog.md) 集中追蹤已確認問題、未交付功能、待驗證項目與批次依賴；先看清單再選實施範圍。
