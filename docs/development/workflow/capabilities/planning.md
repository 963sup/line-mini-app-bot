# 規劃與交付能力

由目前代理承擔計畫、範圍、依賴與最終驗收，依[能力入口](README.md)按需選用其他指引。

1. 定義行為、限制、成功條件及已有變更；按風險與效益排序工作，列出總數與驗收證據。
2. 用 Graphify 定位關係，以當前來源及限定 Repomix 內容確認。工具按問題選用，重用仍有效的查證結果。
3. 業務修改先確認操作契約；版本或外部規格依根指引的官方來源路由查證。查證不授予外部寫入權限。
4. 同一代理依序探索、設計、實作、自我審查與測試；同檔案的其他聊天修改先釐清所有權。
5. 驗證完整差異，僅重跑因新變更失效的檢查。缺少證據時列出具體缺口，不能以信心代替通過。
6. 回報完成項目、命令結果、跳過項目及風險；交接使用既有六欄格式。提交、推送與部署另依授權。
