# 規劃與交付能力

由目前代理承擔計畫、範圍、依賴與最終驗收，依[能力入口](README.md)按需選用其他指引。

1. 定義行為、限制、成功條件及已有變更；為每項使用者要求選擇能直接判定成敗的證據，再按依賴與風險安排工作。
2. 沿用已核實的入口。已知檔案可直接查閱；需要探索關係或使用者指定工具時，依根指引查證並回到當前原始檔。
3. 業務修改先確認操作契約；版本或外部規格依根指引的官方來源路由查證。查證不授予外部寫入權限。
4. 按任務選用能力；修改其他聊天正在編輯的檔案前，先釐清所有權。
5. 驗證完整差異，僅重跑因新變更失效的檢查。驗收缺少證據時，先執行授權範圍內可取得該證據的檢查。若仍受阻，記錄實際障礙與受影響的交付項目。
6. 回報完成項目、命令結果、跳過項目及風險；交接使用既有六欄格式。提交、推送與部署另依授權。
