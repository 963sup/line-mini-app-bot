# 任務規劃與交付

依使用者的目標與風險決定範圍、工具和驗收；利用現有資訊解決可推知的問題，缺少必要決策時明確提問。「繼續」時從未完成項目接手；保留既有變更，同一檔案有其他聊天正在修改時先釐清所有權。沿用仍有效的證據。跨聊天移交依[交接指引](../handoff.md#minimal-handoff-and-evidence-reuse)，提交、推送與部署依[發布流程](../publication.md#repository-publication)及任務授權。

<a id="delegation-depth-and-role-selection"></a>

能力指引是供目前代理選讀的 Markdown。專案設定未覆寫 `multi_agent` 或註冊子代理；執行規則見[根指引](../../../../AGENTS.md#單一代理與能力選用)。按任務選擇 Graphify、Repomix 或其他工具，並核對當前聊天實際曝光的 MCP 與技能。
