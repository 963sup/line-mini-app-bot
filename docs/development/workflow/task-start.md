# 開始任務與能力選用

目前代理直接完成任務，不啟動子代理。

1. 確認分支、HEAD、工作樹、既有變更及本次操作授權。
2. 定義預期行為、成功條件與驗收命令；依風險及效益排序工作項目。
3. 從[能力入口](capabilities/README.md)按需閱讀探索、設計、實作、自我審查、測試或文件指引。
4. 依序修改與驗證，保留其他聊天的變更；同檔案正在修改時先確認所有權。
5. 回報工作總數、完成率、實際檢查及剩餘風險。自我審查不可宣稱為獨立審查。

## 單一代理執行

`.codex/config.toml` 停用 `multi_agent` 且不註冊子代理。專業能力保存為普通 Markdown，按需讀取；不依賴角色選擇或額外模型。MCP 與 Skills 保持各自設定，工具存在不代表已由當前聊天載入。

錯誤與測試失敗依[除錯流程](debugging.md)處理。工具按任務使用，不強制每次完整執行 Graphify、Repomix 或所有 MCP。

## Assignment contract

同一聊天也需記錄目標、檔案範圍、依賴、必須保留的行為及驗收條件。跨聊天交接使用[六欄交接](handoff.md)，不增加發布或部署權限。
