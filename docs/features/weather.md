# 群組位置天氣

Bot 在群組收到 LINE 內建「分享位置」訊息後，直接回覆目前有效時段的縣市天氣預報。
私訊位置、地圖網址、一般文字不觸發。沒有名單、訂閱、排程或位置儲存。

部署環境注入 `CWA_API_KEY`（氣象資料開放平臺會員授權碼）；未設定時回覆尚未設定。
API Key 不放進前端或日誌。此功能不需要 Firestore，不影響出勤的設定。

使用 `F-D0047-091` 縣市未來一週預報，讀取目前有效的「天氣預報綜合描述」，直接呈現官方溫度、降雨及天氣文字。
先用 LINE 位置地址中的縣市名稱比對（兼容台／臺），代表點距離不得超過 100 公里。
沒有相符地址時，以球面距離選最近的官方代表點，最多 60 公里，回覆明確標示「鄰近縣市預報」。
這是基礎區域近似，不是行政區邊界判定、鄉鎮定位或座標即時觀測；山區與縣市邊界尤其需注意。
不支援的遠端位置、過期預報或上游錯誤不回傳虛構天氣。

每次分享查詢一次 API，3 秒逾時、4 MiB 回應上限，不自動跟隨重新導向。第一版沒有快取或背景工作。
重送位置事件不再次查詢；回覆失敗不保證送達，使用者可重新分享。

來源：氣象署 [API 說明](https://opendata.cwa.gov.tw/dist/opendata-swagger.html)、
[資料集](https://opendata.cwa.gov.tw/dataset/forecast/F-D0047-091)、
[產品格式說明](https://www.cwa.gov.tw/Data/data_catalog/1-1-1.pdf)。
直接連線目前回傳 403，欄位依官方網頁搜尋摘錄核對；仍需有效 API Key 做真實資料驗收。
