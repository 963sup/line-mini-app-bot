# LINE 任務接線表

依任務查找 1:1 私訊、群組或 MINI App 入口，以及後端分派、回饋和驗收條件。「已有」表示程式或現有規格具備該接線，正式渠道仍須實機驗收。「目標」表示旅程設計，實際按鈕、路由及通知尚待落實或核對。

文字指令和 Message Action 走 `message`，Postback Action 走 `postback`。URI Action 直接開啟目的頁。App 登入與提交走 [Session](mini-app-identity.md) 和業務 API。後端主動發送通知依接收資格選擇渠道。事件驗簽與重送見 [Webhook 規格](webhook.md)，完整情境見 [LINE 使用者旅程](journey.md)。

## Rich Menu 圖片與按鈕配置

三張 **2500 × 1686 px JPG**。上班為預設頁。上排固定為「上班｜轉場支援｜下班」，當前分頁只顯示選中樣式。另兩個分頁可切換。下排三格合併成一個主操作熱區，在私訊回覆指引。

| 圖片                      | 上排可切換     | 下排主操作                   |
| ------------------------- | -------------- | ---------------------------- |
| `rich-menu-clock-in.JPG`  | 轉場支援、下班 | 上班 → `action=clock-in`     |
| `rich-menu-transfer.JPG`  | 上班、下班     | 轉場支援 → `action=transfer` |
| `rich-menu-clock-out.JPG` | 上班、轉場支援 | 下班 → `action=clock-out`    |

上班及下班須在正確群組發起打卡，再由 MINI App 驗證及提交。人在 B 支援時，轉場指引會請他先確認 A 班次如何計算；入口不會結束 A 或新增 B 班次。正式渠道需驗證九個可點熱區，並確認選中的分頁不送出 Action。[發布規格](../../operations/rich-menu.md) · [格線與產生器設計](../../development/tooling/shared/rich-menu-generator.md)
