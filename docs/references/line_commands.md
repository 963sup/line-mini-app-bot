# LINE Bot 聊天指令

在與官方帳號的私聊或有 Bot 的群組輸入下列文字。指令表依目前程式碼整理；線上可用性仍取決於部署版本、渠道設定與使用者權限。

## 私聊與群組

| 指令                    | 用途                                                               |
| ----------------------- | ------------------------------------------------------------------ |
| `選單`、`功能`、`/menu` | 私聊提示使用 Rich Menu。群組顯示本群組出勤及已綁定的儲存庫。       |
| `/help`                 | 依聊天來源提供與「功能」相同的說明或入口。                         |
| `/miniapp`              | 取得 MINI App Buttons Template。已設定網頁入口時支援桌面替代連結。 |

## 群組

| 指令                 | 用途                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------ |
| `打卡`               | 開啟本群的上班、下班、休息開始、休息結束及確認休息選項，再依提示進行本人驗證和定位。 |
| `出勤`               | 查看本群上班中、休息中與今日已下班的紀錄統計。                                       |
| `漏下班`、`下班提醒` | 查詢發話者在本群是否有未結束班次。                                                   |
| `補卡`               | Quick Reply 顯示「補卡」；申請遺漏的上班、下班或整班紀錄。核准前有效紀錄不變。       |
| `更正`               | Quick Reply 顯示「更正」；先選擇既有出勤紀錄，再申請修改錯誤時間。                   |
| `請假`               | Quick Reply 顯示「請假」；取得本群請假表。送出後仍須依流程確認。                     |
| `摘要`               | Quick Reply 顯示「摘要」；摘要最近 24 小時的群聊，最多 100 則。                      |

直接輸入 `上班`、`下班`、`休息開始`、`休息結束` 或 `確認休息` 會收到操作引導。出勤只在完成 `打卡` 選單中的驗證流程後寫入。群組也可分享位置查天氣，這是位置訊息操作。

## 私聊

| 指令                                 | 用途                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| `出勤紀錄`                           | 查看本人出勤，依畫面選群組與月份。                                            |
| `出勤紀錄 1`                         | 依本人群組清單的編號選擇群組，再選月份。                                      |
| `我的工程`                           | 查詢本人可存取的工程儲存庫及入口。                                            |
| `建立組織`、`建立企業`               | 開始建立流程，五分鐘內回覆名稱；流程中可輸入 `取消`。企業建立須符合開通資格。 |
| `邀請加入 組織ID`                    | 有組織邀請權限時產生邀請碼。                                                  |
| `接受邀請 邀請碼`、`撤銷邀請 邀請碼` | 依邀請狀態與權限接受或撤銷邀請。                                              |

## 私聊 Rich Menu

使用一張 **2500 × 1686 px JPG**，上排為「出勤、補卡、更正」，下排為「請假、審核、儲存庫」。每格直接開啟對應的 MINI App 頁面。審核資料依既有權限提供。請假頁可查詢本人紀錄，提出申請仍需從群組取得請假入口。

群組一般聊天與 Bot 入群保持安靜。明確輸入「功能」或使用已設定的選單貼圖才顯示本群組入口。群組專用的「打卡」等指令仍可直接使用。
