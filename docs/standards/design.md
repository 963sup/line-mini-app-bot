# 產品與體驗設計原則

十二個服務入口的元件選用、互動狀態與驗收方式見 [LINE MINI App UI 設計規格](miniapp-ui.md)。

## 核心定位

頂尖設計師的價值，不只是讓產品看起來漂亮，而是**理解正確的使用者問題，以最少必要複雜度創造清楚、有效、一致、可驗證的體驗**。

## 六大核心原則

| 核心原則    | 關鍵問題                           | 實踐標準                                 |
| ----------- | ---------------------------------- | ---------------------------------------- |
| 1. 問題正確 | 使用者真正需要解決什麼問題？       | 定義使用者、情境、需求與成功標準         |
| 2. 模型正確 | 使用者如何理解資訊與操作？         | 建立清楚的心智模型、資訊架構與概念關係   |
| 3. 設計簡單 | 如何用最少的認知與操作完成目標？   | 降低認知負荷、操作步驟與不必要的選擇     |
| 4. 體驗可靠 | 使用者是否能理解、操作並處理異常？ | 確保一致性、可理解性、回饋、容錯與無障礙 |
| 5. 驗證充分 | 如何證明設計真正有效？             | 使用者測試、可用性評估與行為數據驗證     |
| 6. 持續改善 | 哪些摩擦、混亂與複雜度可以消除？   | 簡化流程、整合元件、優化設計系統並量測   |

## 核心思想

先確保解決正確的使用者問題，再以符合心智模型的最簡單設計呈現，透過真實使用情境驗證體驗，最後持續消除認知負擔與操作摩擦。

**目標明確、理解容易、操作直覺、體驗一致、錯誤可恢復，且每一次設計決策都能被驗證。**

## 評估指標

| 評估指標       | 衡量方式                               |
| -------------- | -------------------------------------- |
| 目標達成率     | 使用者成功完成核心任務的比例           |
| 理解效率       | 理解資訊、功能及下一步操作所需時間     |
| 操作效率       | 完成任務所需時間、步驟與互動次數       |
| 操作準確性     | 首次操作成功率、錯誤率及誤操作次數     |
| 認知負荷       | 使用者困惑程度、決策難度與主觀負擔     |
| 體驗一致性     | 相似操作的行為一致程度及設計規則遵循率 |
| 可用性與無障礙 | 不同使用者及裝置完成核心任務的能力     |
| 設計維護成本   | 重複元件、例外樣式、設計債與同步負擔   |

## 決策準則

**正確的問題 → 正確的心智模型 → 最簡單的互動 → 可靠的體驗 → 可驗證的結果 → 持續降低複雜度。**

設計選擇應同時衡量使用者效益、可用性、實作限制與長期維護成本，避免把系統複雜度直接轉嫁給使用者，也避免為減少操作步驟而產生不成比例的工程負擔。
