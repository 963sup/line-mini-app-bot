# 儲存庫物件

提供物件清單、詳情、手動新增及建立者編輯；欄位、權限與狀態依 [物件規格](../../../../../docs/features/repository/objects.md)。另提供選擇文字型PDF後本機擷取明細、自動解析保存並顯示結果／編修；規則依 [PDF匯入規格](../../../../../docs/features/repository/object-imports.md)。不提供掃描OCR、CSV匯入、單位換算或財務操作。

`View` 依儲存庫及身分世代重設狀態，未知建立結果保留原請求鍵及內容；父層導覽在建立結果未確認時保持目前表單。沿用既有 typed client、請求取消及官方 UI 元件組合。
