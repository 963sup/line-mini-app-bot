# 儲存庫工程項目

提供 Objects 清單、詳情、手動新增及建立者編輯；欄位、權限與狀態依 [工程項目規格](../../../../../docs/features/objects.md)。另提供本機文字型PDF預覽、選頁與遮蔽文字後的AI解析草稿，再由人工審查與明確確認；規則依 [PDF匯入規格](../../../../../docs/features/object-imports.md)。不提供掃描OCR、CSV匯入、單位換算或財務操作。

`View` 依儲存庫及身分世代重設狀態，未知建立結果保留原請求鍵及內容；父層導覽在建立結果未確認時保持目前表單。沿用既有 typed client、請求取消及官方 UI 元件組合。
